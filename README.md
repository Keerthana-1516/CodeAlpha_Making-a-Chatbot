# CodeAlpha Internship Project - Task 4: AI Chatbot 🤖

Project Title

AI-Powered Chatbot using Python and Streamlit

Project Description

This project is developed as part of the CodeAlpha Internship (Task 4). It is a simple AI-powered chatbot built using Python and Streamlit that provides instant responses to user queries based on predefined patterns. The chatbot demonstrates the basic implementation of conversational AI with a web-based interface.

Key Features

- Instant response system for user queries  
- Rule-based chatbot logic using predefined patterns  
- Interactive web interface using Streamlit  
- Lightweight and beginner-friendly implementation  
- Easily extendable for advanced AI integration (e.g., Gemini/OpenAI APIs)

Technologies Used

- Python  
- Streamlit  

Project Structure

- app.py → Main application file containing chatbot logic  
- requirements.txt → List of required dependencies  
- README.md → Project documentation  

How to Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
